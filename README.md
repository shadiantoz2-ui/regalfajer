# Regalfajer

أريد إنشاء موقع اسمه رجال الفجر



الموقع عبارة عن تسجيل حضور الطلاب بحيث يقوم الطالب عند الدخول بالتلفظ باسمه والموقع يعرض له الاسم الذي قاله بصوته اذا كان صحيح يضع تم واذا لا يقوم بإعادة التلفظ باسمه



سيكون هناك قسم لإدخال كل أسماء الطلاب ( الاسم الثلاثي ) وعند إدخال طالب ولم يكن موجود ضع خيار لتسجيل هذا الطالب من جديد



لا يوجد تكرار للحضور



أستطيع إدخال حضور لطلاب بأوقات ماضية بحيث أقول اسم الطالب وأسجل بأي تاريخ حضر



وضع زر لتحميل بيانات حضور الطلاب بحيث يعرض يام أسماء الطلاب كاملة وكل طالب الأيلم التي حضر بها ( الحضور يومي سيكون غالبا)

ضع هذا الشعار الذي أرسلته فوق عنوان رجال الفجر



الأرقام اجعلها باللغة الانكليزية



عند تكرار اسم أعط تنبيها بلون أحمر

اريد تصميم الموقع بحيث يكون تصميم احترافي وجميل ومميز
